# Assets

Recommended layout:

```text
assets/
  images/
    teaser.png
    overview.png
    architecture.png
    comparison.png
  videos/
    teaser.mp4
    result-01.mp4
  meshes/
    example.glb
  papers/
    paper.pdf
    supplement.pdf
```

After adding assets, update paths in `../site.config.js`.
